# Contributing

Thank you for your interest in improving this research software.

1. Open an issue describing the bug, experiment, or proposed change.
2. Create a focused branch and keep unrelated changes separate.
3. Preserve the published seed ranges when comparing against reference results.
4. Add or update a test when changing simulation or metric logic.
5. State the Python, PyTorch, operating-system, and hardware versions used for new timing results.

Do not commit participant data, credentials, manuscript review correspondence, generated model weights, or publisher-restricted files.
